# 🛒 Blinkit Sales Performance Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard built to analyze Blinkit's sales performance. The dashboard provides insights into sales, customer ratings, outlet performance, and product categories. It helps businesses understand sales trends and make better decisions using data.

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Compare sales across different outlet types and locations.
- Identify the best-selling product categories.
- Track average sales and customer ratings.
- Create an interactive dashboard for business insights.

---

## 🛠️ Tools & Technologies

- Power BI
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Microsoft Excel
- CSV Dataset

---

## 📊 Dashboard Features

- Total Sales KPI
- Average Sales
- Number of Items Sold
- Average Customer Rating
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Item Type
- Outlet Performance Analysis
- Interactive Filters and Slicers

---

## 📈 Key Insights

- Total Sales: **$997K**
- Items Sold: **7K**
- Average Sales: **$141**
- Average Rating: **3.96**
- Supermarket Type 1 generated the highest sales.
- Fruits and Snacks were among the top-selling product categories.
- Tier 2 outlets contributed the highest sales.
